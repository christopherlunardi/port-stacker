# Port Stacker Deluxe (repo: port-stacker): project notes

What Chris asked for and what was decided. Newest at the bottom of each section. Add to it as we go.
Started 2026-11-06 as a quick concept ("Stack Style"); moved to this repo with a fresh history on 2026-11-11 once it turned into the real game.

## What the game is
- Buck, a dock worker, loads shipping containers onto a ship at a busy port, with a lot of modern movement and scoring on top of a simple
  arcade loop. Must play well on a tiny screen and in 4K, 4:3 and every modern shape, and on Chris's Retroid Pocket 2S and Pocket 6.
- Repo christopherlunardi/port-stacker is public so the launcher can download builds without a login.

## How it's played
- Core: walk across all four panels of a container and it drops a catwalk, knocking down the container below; at the bottom it loads
  into a bay on the ship. All bays full = the ship sails off, stage clear. Enemies standing on a dropped container ride it down (each rider
  = one extra catwalk, big bonus); enemies under it get squashed. The air horn stuns. - Modern movement: ladders and catwalk edges snap you on from 5px away; the last direction pressed wins at crossings (the other is tried
  when blocked); B dashes; the horn aims the way you face; score combos and chains; 1UP every 20000.
- Buttons: A horn, B dash, Start pause menu, Select (free for now). Keys: arrows/WASD, Z/Space/J, X/Shift/K, Enter/Esc/P, Tab.

## Screens (2026-11-06)
- The field is fixed at 320x240 game pixels, drawn at the biggest whole-number scale that fits: Retroid 2S 640x480 = 2x exactly,
  Pocket 6 1080p = 4x (480x270 with side panels), 4K = 9x, phones 3-4x. Extra room becomes side panels (score, stage, horns, lives).
- Phone layout copies Hereafter Man's console: screen on top, d-pad and A/B below (beside it in landscape), Select/Start pills.
  A controller (padmode) or the app (inapp) hides the buttons and the screen fills the window in any shape.
- Dev panel can preview other screens (Retroid 2S, Pocket 6, 4K, tall phone, iPad, ultrawide).

## Dev mode (2026-11-06, same ways in as Hereafter Man)
- On automatically for the artifact's owner (claude.ai user check), opened from a file, or inside the launcher (it loads the game from a file).
- Secret combo anywhere: DOWN DOWN UP UP RIGHT LEFT RIGHT LEFT B A. Or the dev code (same code as Hereafter Man): hold the title bar
  about a second or tap it five times. Remembered on that device.
- DEV button in the title bar or ` opens the panel (stages, cheats, screen previews). The pause menu also gets DEV: lines, so it all
  works with buttons on the Retroid.

## Retroid launcher (2026-11-06)
- Android's WebView doesn't hand controllers to pages (learned on Hereafter Man), so the app reads the buttons and calls ssKey().
  A/Y = A, B/X/L/R = B, Start/Back = Start, Select = Select, d-pad and left stick = directions. Unknown buttons show a toast so we learn them.
- On launch it checks dist/version.json on GitHub (API first, raw.githubusercontent second), downloads dist/stack-style.html if the build
  is newer (checked against its sha256), and plays the newest build it has; offline it plays what it has. The game also ships inside the
  app for a fresh install. Coming back to the app checks again; a new build shows a banner, and the pause menu gets LOAD NEW BUILD
  (or CHECK FOR UPDATE), plus EXIT GAME.
- Install once: https://github.com/christopherlunardi/port-stacker/releases/download/launcher/PortStacker.apk (open on the Retroid, allow
  installs from the browser). Then add it to Daijisho like any Android app. Reinstall only when android/ changes.
- Signed with android/stackstyle-sideload.jks so new launcher builds install over old ones. The app id stays com.ghostjail.stackstyle
  (changing it would make a second, separate app on the handhelds).
- Version codes are the Actions run number + 100 (the old repo's launcher had reached 13), so builds from this repo install over it.

## The dock theme (2026-11-06)
- A dock worker loads shipping containers onto a ship. Containers are 8 tiles wide (64x14); walk across all of them and it drops a
  catwalk. Bays on the ship take 4 each. The ship sails off when every bay is full (stage clear) and the next one pulls in.
- Look: riso print, inks pink / blue / yellow on paper. Art is painted onto three ink plates at game pixels; a WebGL shader prints them
  at screen resolution (rotated halftone screens, slight misregistration, dropouts, paper grain). Flat colours if WebGL is missing.
  Chris's reference: a ChatGPT concept poster ("Port Stacker Deluxe") with this look.

## Drawn art (2026-11-06)
- Chris moved from pixel art to flat cartoon art in the riso look, from ChatGPT (his concept image is the target vibe). Hero: Buck.
  Enemy: Inspector Pratt. Containers have 4 panels (walk across all four). Backdrop: ChatGPT harbor painting, printed faded (his pick B)
  with drifting mist. Buck and Pratt have 4-frame walk cycles from ChatGPT; Buck's sheet repeats the near leg forward (redo frame 3 if
  it bugs him). An early hero and dock boss looked too much like a famous existing character and were dropped: every design is our own.

## Second enemy (2026-11-07)
- Crab: a catwalk guard, not a chaser. Never climbs; patrols; when Buck is on its catwalk within ~150px it winds up (shakes, "!") for
  about half a second, charges at ~3x speed until it passes him or hits the end, then rests. Spawns at any catwalk end. Stage 1 roster:
  pratt, crab, pratt. Chris likes it as a unique challenge.
- The horn blasts the way Buck faces on a catwalk; up/down only on a ladder (a resting thumb on the phone d-pad aimed it down).
- Base speeds: Buck 1px/2 frames, walkers 1px/4 frames; doors in turn, first ~1.8s, then every 80 frames.

## Campaign shape (agreed 2026-11-07)
- Every stage is its own puzzle and gets harder. Plan: a campaign of hand-built stages (start with 4 worlds x 4 stages); each stage
  introduces one new idea and tests it (e.g. first crab, gaps in catwalks, ladders that appear once a column is full, a container that
  must drop twice, a crane hook, lights-out sections); each world's last stage mixes its ideas. Difficulty comes mainly from the puzzle
  (more containers per bay, fewer ladders, enemies placed to cut routes), with speed creeping up a little per world.
- After the campaign: an endless arcade-style mode that loops and keeps speeding up, for high scores.
- Stage 1 = HARBOR PIER (for now). Stage 2: to decide with Chris.

## Scoring and the leaderboard (2026-11-07)
- It's all about score. Game over with a top-10 score -> enter 3 initials (up/down letter, left/right move, A ok), arcade style; the
  board (on this device) shows initials, score and stage reached; the title and the board take turns.
- Balance (pay for difficulty and risk): one rider 300 (easy); 2/3/4 riders 1500/6000/20000 (luring a group is the jackpot); squash 800,
  doubling for each more under the same drop. Container drop 50 per floor, bay full 1000, stage clear 1000+, combos multiply.

## Play log (2026-11-07)
- 14-telemetry.js logs session (device, build, screen, GPU), stage clears (stage, score, seconds, deaths), deaths (by which enemy),
  game overs (score, stage, run length) and errors. On the claude.ai link they go to the artifact's database, collection `telemetry`
  (only the owner can read; read it with ArtifactData list). In the Retroid app they stay on the device (localStorage 'telemetry', last 200).
- Use it to tune difficulty: where people die, how long stages take, which devices error.
